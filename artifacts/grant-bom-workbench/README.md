# Grant BOM Workbench

Browser and Node module for exact integer-cent Bill of Materials budgeting, supplier quote validation (DigiKey, Mouser, OSH Park, LCSC, Adafruit, SparkFun, Pololu), stale-quote detection, and schema-validated JSON import/export for hardware microgrants such as the Hack Club 8-Pin Grant.

## Run tests
```sh
npm test
npm run test:browser
```
